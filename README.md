# 色時計 (iroirotokei) — M5Stack StopWatch

M5Stack StopWatch (ESP32-S3 / 1.75インチ円形AMOLED 466×466) 用のファームウェア。
24bitカラー (1677万色) の AMOLED 画面全体を「色」として使います。

## 機能

### 1. 色時計
24時間を通して、背景色が **深夜の紺 → 朝焼け → 昼の青空 → 黄金の時間 → 夕焼け → 夕闇 → 夜** と秒単位でゆっくり滑らかに変化します。
画面の縁には「その日1日分の色」のグラデーションリングが表示され、白いマーカーが現在時刻の位置を示します。中央に時刻・日付・現在の色コード (#RRGGBB) を表示。

- **タイムトラベル**: 画面にタッチして円をなぞると、その角度の時刻の色を覗けます (文字盤=24時間)。「時」を越えるたびにその色の音が鳴り、指を離すと現在に戻ります。
- **タイムラプス**: 右ボタン長押しで、1日の色の旅を約48秒で再生。1時間ごとにその色の音が鳴り、1日が色とメロディで流れます (ボタンで中断)。

### 2. 色づくり
パレットの色を混ぜ合わせてオリジナルの色を作るモード。混ぜるたびに累積平均で色が合成されるので、組み合わせ次第で1677万色のどの色にも近づけられます。
**本体を振る**と1677万色から完全ランダムな色が出ます(そこからさらに混ぜて調整可能)。

### 3. 傾き絵の具
IMU(BMI270)を使った水彩あそび。本体を傾けると、傾けた側に絵の具が流れ込み、
低い側ほど色が濃く積もります(強い場所と弱い場所)。毎フレームのにじみ処理で
隣どうしの色が水彩絵の具のようにじわっと混ざります。
左右のボタンでそれぞれの絵の具つぼの色を選択。傾けている間はキラキラした音が鳴り、
傾きが強いほど音が大きく・速くまたたきます。

### 4. 声の色
マイクに話しかけると、**声の高さ→色相、声の大きさ→明るさ**に変換されてリアルタイムに色が変わります。
話し終わると「あなたの声の色」がペンタトニックの音になって返ってきます(右ボタンでもう一度)。
低い声は赤っぽく、高い声は青紫っぽく。歌ってみると色が踊ります。

### 5. ストップウォッチ
ラップ機能付き (1/100秒表示)。

### 6. Unit Hex 連動 (オプション)
PortA に [Unit Hex](https://docs.m5stack.com/ja/unit/hex) (SK6812×37) を接続すると、
37個のLEDが**すべてのモードの「いまの色」**と連動して光ります。

| モード | LEDの色 |
|---|---|
| 色時計 / ストップウォッチ | 1日の空の色 (画面と同じ) |
| タイムトラベル / タイムラプス中 | プレビュー中の時刻の色 |
| 色づくり | 混ぜてできた色 |
| 傾き絵の具 | 画面全体の平均色 (混ざり具合がそのまま) |
| 声の色 | 声の色 |

時計画面で**左ボタン短押し=LEDのオン/オフ**、**左ボタンダブルクリック=明るさ調整画面**。
調整画面では左ボタンで暗く・右ボタンで明るく (押しっぱなしで連続変化、2〜100%)、
3秒そのままにすると決定して時計に戻ります。どちらの設定も保存されます。
電力保護のためFastLEDの上限を5V/500mAに制限しています。未接続でも動作に影響はありません。

### 7. 音 (星・空・地球のイメージ)
- **モード切替時**: 星のまたたきのような2音
- **色を混ぜたとき**: できあがった色が音になる (色相→ペンタトニック音階の高さ)
- **毎正時**: 遠い鐘のような上昇アルペジオ
- **オン/オフ**: 色時計画面で右ボタン短押し (設定は本体に保存)

## 操作方法

| 操作 | 動作 |
|---|---|
| **左ボタン(KEYA/黄) 長押し** | モード切替 (色時計 → 色づくり → 傾き絵の具 → 声の色 → ストップウォッチ) |
| 色時計: 左短押し | LED (Unit Hex) のオン/オフ |
| 色時計: 左ダブルクリック | LEDの明るさ調整画面 (左:暗く / 右:明るく / 3秒放置で決定) |
| 色時計: 右短押し | 音のオン/オフ |
| 色時計: 右長押し | 1日の色を約48秒で再生 (タイムラプス) |
| 色時計: タッチしてなぞる | その時刻の色を覗く (タイムトラベル) |
| 色づくり: 左短押し | パレットから色を選択 |
| 色づくり: 右短押し | 選んだ色を混ぜる |
| 色づくり: 右長押し | 混ぜた色をリセット |
| 色づくり: 本体を振る | ランダムな色を出す |
| 声の色: 話しかける | 声がリアルタイムに色になる |
| 声の色: 右短押し | 声の色の音をもう一度聴く |
| 傾き絵の具: 左短押し | 左の絵の具つぼの色を選択 |
| 傾き絵の具: 右短押し | 右の絵の具つぼの色を選択 |
| 傾き絵の具: 本体を傾ける | 傾けた側へ絵の具が流れて混ざる |
| 傾き絵の具: 右長押し | 紙をリセット |
| ストップウォッチ: 左短押し | スタート / ストップ |
| ストップウォッチ: 右短押し | ラップ (計測中) / リセット (停止中) |

※ 左右ボタンの物理配置が逆に感じる場合は `src/main.cpp` の `btnL()` / `btnR()` の割り当てを入れ替えてください。

## 時刻合わせ

### Wi-Fi自動同期 (推奨・初回設定だけでずっと自動)

1. **右ボタンを押しながら電源オン** → 画面に「Wi-Fi設定モード」と表示
2. スマホのWi-Fi設定を開き、アクセスポイント **「iroirotokei」** に接続
3. 自動で開く設定画面 (開かなければブラウザで 192.168.4.1) で自宅のWi-Fiを選び、パスワードを入力
4. デバイスが再起動して完了

以降は**起動するたび+毎日午前3時**に、インターネット時刻 (NTP) へ自動で合います。
同期後はWi-Fiを自動オフにするので電池への影響はわずかです。時刻はRTCにも書き込まれます。

### 手動 (Wi-Fiがない場合)

PCとUSB接続してPowerShellから:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\set_time.ps1
```

またはシリアルモニタ (115200bps) から: `T 12:34:56` / `D 2026-07-13 12:34:56` / `N` (今すぐNTP同期)

## ビルドと書き込み (VSCode + PlatformIO)

1. VSCode に PlatformIO IDE 拡張機能をインストール
2. このフォルダを VSCode で開く (初回はライブラリとツールチェーンが自動ダウンロードされます)
3. デバイスを **ダウンロードモード** にする: 電源ボタンを押しながら USB 接続 (詳細は[公式ドキュメント](https://docs.m5stack.com/ja/arduino/stopwatch/program)参照)
4. PlatformIO の「Upload」(→ アイコン) で書き込み

## 色時計のカラーテーブル

`src/main.cpp` の `DAY_COLORS[]` で時刻ごとのキーカラーを定義しています。
好みの色に変えたい場合はここを編集してください (分, R, G, B)。区間は自動で線形補間されます。
